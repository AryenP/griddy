   operator a second token (operator QR vs owner QR) or bind the owner to the join link.
6. **LOW: an empty token file fails open.** `operator_token()` (access.py:31-41) returns the file's text; if
   runs/.operator_token exists but is empty (a crash between O_EXCL create and write), `joined()` compares "" with ""
