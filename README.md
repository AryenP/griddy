# Brownout

Grid-responsive AI compute agent. A utility asks for a power cut; Brownout pauses the work that can wait, keeps interactive latency intact, asks owners before touching their jobs, proves the reduction on an independent wall meter, and reports the shortfall honestly when the target is impossible.

Start with `CLAUDE.md`, then `PLAN.md`. Nothing is simulated: `make probe` checks this Mac, `make demo` runs live.
